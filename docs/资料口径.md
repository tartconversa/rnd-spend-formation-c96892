# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

订单line_id可分期验收。承诺是尚未形成支出的有效订单量，receipt为实收、acceptance为内部确认支出条件，付款不证明收货。耗材验收即费用，service按已验收服务费用，equipment及installation先归资产。asset.ready_at为内部启用时点；按月直线分担，使用年限36月，无残值；当月启用从次月开始，后补启用前成本从补齐月起重算剩余月度额，原管理包可比较而不改原内容。共享成本按各月usage实际小时分担；coverage_fraction未达1的部分保留待分，不按有记录者归一到100%。出资比例仅解释预算承担，不代替usage。组织归属按effective日期解释历史，当前视角按查询日组织；汇率缺日不自行插值，CNY为1。invoice正向为应付证据，credit为票据红冲；return为物理退货，refund为现金退还，三者独立。revisions是后续单独接收的订单总量修订，不得小于已实际形成义务而抹除差额。

## revisions

记录键：['revision_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| revision_id | string | 修订 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

已实收未验形成待核义务，不得退回为尚未履约预算。usage同资产同月coverage_fraction一致，项目比例为其hours占已知总hours乘coverage_fraction，剩余待分。启用前安装按实际服务发生日而非发票日判断；补齐月以验收接收月为准，首月不早于启用次月。

本包R4明确退回R2中尚未验收的10件，A2确认的50件不因R4自动减少。后续同格式资料应给退货与原收货及已验收份额的明确关联，否则列待核，不任意选取。RV1是故意小于已确认义务的上游修订，应暴露其冲突而不删除真实验收。L2安装实际发生在R5日，后验收才形成确认支出。
